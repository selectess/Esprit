REVERSALS
The problem

An agent does this by default.
Without meaning to.

The sciences of persuasion were built to make a human act. They work. That is the problem: an agent applies them with no intent, because they saturate the commercial language it is made of.

An agent that says “this will take about three days” has just anchored a human decision on a number it invented, with no intent and with no one noticing.

Not speculation. The Center for Democracy & Technology's May 2026 taxonomy of 37 chatbot dark patterns puts it plainly: with chatbots, dark patterns may emerge from system behaviours rather than a deliberate intent to deceive.

The autonomy contract

It acts alone on everything reversible.
It stops dead on three acts.

A PreToolUse hook enforces all three. It forbids none of these acts. It forbids them being silent.

node kie.mjs shot … ⛔ refused ESPRIT_BUDGET_OK="~3 USD, approved" node … ✓ passes rm -rf ~/project/old ⛔ refused ESPRIT_DELETE_OK="duplicate, diff -rq empty" rm … ✓ passes git push origin main ⛔ refused ESPRIT_PUBLISH_OK="reviewed, go received" git … ✓ passes

The prefix writes the announcement into the session transcript. What is not announced is not executable. This is not a spend cap. It is informed consent, mechanised.

What is actually enforced

Two of eleven are mechanical.
Nine are prose.

Most projects leave this vague. Saying it out loud is reversal 9.

⚙ 01 · Cost before commitment

PreToolUse hook. Blocks the three silent acts. 45-case test suite.

⚙ 05 · No number without provenance

Stop hook. Reads the transcript, flags asserted numbers. Warns, never blocks.

02 – 04, 06 – 09

Prose in the skill. The model chooses to honour them.

10 – 11

Detecting flattery or simulated affect in free text is unsolved. No hook.

The detector's precision came from one insight: the discriminator is not the number, it is what precedes it. “The average basket is 3,000 MAD” asserts, and is flagged. “A product at 3,000 MAD” illustrates, and is ignored. On a 1,691-line corpus: 34 flags with lexical matching alone, 3 with a grammatical assertion filter, 1 after a hypothetical filter (a true positive), and 0 once the corpus was corrected.

Known debts

What it does not do.

  • It is not a security guardrail. It caps nothing and stops no attack. AgentOps and compass do that, and have done it longer.
  • The guard is bypassable by one level of indirection: eval, a subshell, a script. It stops a distracted agent, not a determined one. That is the intended scope: the thesis is that the manipulation here is unintentional.
  • Codex's hook schema has never been exercised. The hooks' commands run and behave correctly against the documented layout, but no Codex runtime has ever loaded the config that invokes them.
  • It is not neutral. Every rule costs speed, fluency, sometimes a yes you would otherwise have obtained. That is the deliberate price.

Repository

Skill governance works on provenance before installation. Esprit works on conduct during execution. A perfectly safe skill can still lead an agent to anchor a decision on an invented number.
